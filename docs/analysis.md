# Анализ предметной области: AccessEvent

## 1. Описание предметной области
AccessEvent — платформа для организации мероприятий с акцентом на доступность для людей с нарушениями слуха.

## 2. Сущности и атрибуты
| Сущность | Атрибуты | Описание |
|----------|----------|----------|
| Event | id, title, date, location, description, is_inclusive | Мероприятие |
| Participant | id, name, email, phone, hearing_status | Участник |
| Organizer | id, name, contact, rating | Организатор |
| Registration | id, event_id, participant_id, status, created_at | Регистрация |
| Notification | id, event_id, type, message, color | Уведомление |
| Review | id, event_id, participant_id, rating, text | Отзыв |
| Category | id, name, description | Категория |
| Message | id, event_id, sender_id, text, created_at | Сообщение |
| Material | id, event_id, title, file_url | Материал |

## 3. Бизнес-процессы
### 3.1. Создание мероприятия
Организатор создаёт мероприятие с датой, местом, описанием.
### 3.2. Регистрация на мероприятие
Участник регистрируется, статус: ожидание -> одобрено/отклонено.
### 3.3. Визуальное уведомление
За 30 минут показывается цветной баннер (зелёный, жёлтый, красный).
### 3.4. Текстовый чат
Участник пишет в чат, организатор отвечает.
### 3.5. Отзыв
Участник оставляет оценку и текст после мероприятия.
### 3.6. Модерация
Администратор блокирует нарушителей.

## 4. Роли
- Организатор
- Участник
- Администратор
- Гость
